# Test status / Estado de pruebas — 2026-11-26

Windows SDK 10.0.28000.0 was restored after an `MSB8036` failure. The final source then built locally with MSVC in **Debug and Release**: `JevaingSandbox`, `JevaingEditor`, `JevaingCSample`, `SkyDodge2D`, `JevaingModuleSmokeTest` and `JevaingModContentTest`. Optional native modules, mods and the 2D sample were enabled in `build-codex`.

Both configurations passed these 26 sandbox checks: `--self-test`, `--renderer-info`, `--asset-cache-test`, `--asset-error-test`, `--scene-serialization-test`, `--hierarchy-test`, `--physics-info`, `--physics-fixed-step-test`, `--physics-3d-test`, `--physics-3d-stack-test`, `--physics-3d-sphere-test`, `--physics-3d-trigger-test`, `--physics-3d-raycast-test`, `--physics-2d-test`, `--physics-2d-circle-test`, `--physics-2d-trigger-test`, `--physics-2d-raycast-test`, `--physics-scene-serialization-test`, `--physics-destroy-test`, `--physics-hierarchy-test`, `--build-target-info`, `--gamepad-test`, `--project-template-test`, `--editor-scene-roundtrip-test`, `--playmode-restore-test` and `--xbox-build-environment-test`. These tests include corrupt/missing file backup recovery, truncated scene rejection and skybox color serialization. The Xbox environment check reports unavailability; it does not establish Xbox support.

Both configurations passed the pure C `--abi-test`, scene roundtrip, two-frame null-renderer lifecycle, `--physics-test` and PNG `--asset-test`. Native module and content mod smoke tests passed in both configurations. The module test covers version/dependency/lifecycle/service checks; the mod test covers disabled policy, compatibility, path confinement and non-destructive content lookup.

Both configurations passed `SkyDodge2D --logic-test` and two-frame null-renderer runs. The game ran 30 frames with DirectX 11 in Debug and Release. A Release copy containing the executable, scene, assets folder and project metadata ran from its package directory with both renderers; the ZIP was also extracted to a temporary directory outside the source tree and ran for two null-renderer frames.

The Debug sandbox ran `--scene-test --renderer directx --frames 30` successfully. A longer interactive run was inspected visually: the procedural sky gradient appeared behind the 3D model, and the packaged 2D game displayed its player, falling objects, background and HUD. No automated pixel comparison or keyboard-interaction assertion was performed.

The generated-project `--windows-build-test` passed in Debug and Release. It configured and built a new game, staged only the selected startup scene, launched the exported executable for two frames with the null renderer and returned success. The test uses a local development machine; it does not establish clean-machine dependencies.

Still unverified: a clean Windows installation, Linux/macOS, remote GitHub Actions result, full editor GUI workflows, actual game code in editor Play, audio, Lua, encrypted source recovery and complete C API coverage. Native modules and content mods cover their implemented subset only. A successful local suite does not make the closed beta ready.
