# Jevaing Xbox Smoke Test

Experimental 0.0.14 smoke target for Xbox Developer Mode / UWP validation.

Current scope:

- start a minimal Jevaing app
- initialize DirectX through the existing runtime path where supported
- draw a triangle and cube
- read controller input through the neutral `Jevaing::Input` gamepad API

Status:

- Windows Desktop build: COMPILED by automated validation when available
- Xbox Dev Mode / UWP package: PENDING local UWP SDK/package validation
- Xbox hardware: PENDING user validation on real console

This is not Xbox GDK support and not a commercial/Game OS console target.
